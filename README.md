# Mayar Issa — Portfolio

My personal site: selected projects, experience and how to reach me.

Built with Next.js, TypeScript and Tailwind CSS, deployed on Vercel.

## Editing

All text lives in `src/content.ts`. To add a project, add an entry to `projects`; to give it a screenshot, put the image in `public/work/` and set `image`.

```bash
npm install
npm run dev    # http://localhost:3000
npm run build
```
